# Seguimiento ODD

ODD organiza el trabajo desde el alcance autorizado hasta la verificación y cierre. SDD complementa ese flujo con specs para definir comportamiento, contratos y criterios de aceptación.

Para trabajo extenso o que requiera continuidad, copiar [tasks/TEMPLATE.md](tasks/TEMPLATE.md) a `tasks/<feature>.md`. Registrar requisitos y referencias, tareas, decisiones, evidencia y pendientes. Actualizar el registro cuando cambie el estado; no declarar completo un requisito sin su verificación aplicable.

El registro de tareas no sustituye las specs. Los cambios pequeños pueden realizarse y verificarse sin crear un archivo de seguimiento. Consultar [CONTRIBUTING.md](../CONTRIBUTING.md) para el flujo y comandos del proyecto.
