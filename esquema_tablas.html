Esquema de Base de Datos TecNM (85 Tablas)

Este documento documenta y visualiza la arquitectura integral de la base de datos extraída de estructura_tablas.sql (origen: scriptAlumnosTEC.sql).

Nota: La base de datos contiene **85 tablas** organizadas en **9 módulos funcionales** para permitir una visualización clara, modular y de alto rendimiento mediante diagramas **Mermaid**.
